Header animation — sample

Ye sirf ek sample page hai. Aapki asli dashboard files me abhi kuch nahi badla gaya. Upar ka header bilkul wahi design hai — sirf do animations add ki gayi hain.

1. Swoosh wave

Page khulte hi safed/kesari wave baayein se andar aati hai (1.5s, ease-out), phir hamesha ke liye bahut halki si drift karti rehti hai (8s ka chakkar). Golden line par ek dhimi chamak baayein se daayein chalti hai. Text, chips aur Admin button kabhi nahi dhakte.

2. Logo coin flip

Logo par click karo — ya Tab se select karke Enter / Space dabao — to wo sikke ki tarah poora 360° ghoomta hai (0.9s) aur beech me halka sa bada hota hai. Flip chalte waqt dobara click kaam nahi karega.

Timings badalni hain?

Sirf :root ki 5 CSS variables: --swoosh-intro-duration, --swoosh-idle-duration, --swoosh-shimmer-duration, --logo-flip-duration, --hdr-fade-duration.

Windows me “Show animations” band hai to intro aur drift apne aap ruk jayengi (prefers-reduced-motion).
