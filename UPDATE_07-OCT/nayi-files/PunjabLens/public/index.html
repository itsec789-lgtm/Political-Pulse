Data Source

MongoDB

This dashboard runs live off MongoDB — database political_lens, Punjab data only. Tweets are de-duplicated by Tweet ID, so nothing is ever counted twice.

When new data arrives, run python build_punjab_data.py --push first, then hit Reload here.

Offline / Backup File

If MongoDB is unavailable you can load an Excel (.xlsx), CSV or JSON export instead — it is parsed in the browser, with the same de-duplication by Tweet ID.

AI for Reports

Off

Add a Google Gemini API key — it powers the AI analysis in Reports. The key lives on the server in ai_config.json and never reaches the browser. Without a key, Reports still work — only the AI narrative is skipped.

Get a key from aistudio.google.com → Get API key. Once saved, the model list is fetched live from Google, so any model that is retired simply disappears from the list. Only the dashboard’s aggregate numbers are sent to the model — never raw tweets — so it cannot invent facts of its own.
